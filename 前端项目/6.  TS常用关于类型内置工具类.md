## ==6.== TS常用关于类型内置工具类

<kbd>2025.09.09</kbd> [参考来源：超实用TS提升开发效率的常用内置工具类](https://juejin.cn/post/7345071481376456739)

> ==**Omit 省略/排除**==
>
> > `Omit`是一个泛型类型，用于从一个给定的类型中`排除某些属性`，返回一个新的类型。它接收两个参数，第一个参数是需要omit操作的类型，第二个参数是需要排除的属性的名称或联合类型
> >
> > ```ts
> > interface IUser {
> >   readonly name: string;
> >   age: number;
> >   sex: 0 | 1;
> >   address: string;
> > }
> > // 排除age、sex
> > type Person = Omit<IUser, "age" | "sex">;
> > // 结果就是
> > // {
> > //    readonly name: string;
> > //    address: string;
> > // }
> > ```
>
>
>
> ==**Pick 选择**==
>
> > `Pick`是在已经定义的对象中`选取所需属性`
> > `pick<T，keys>`：从`Type`中选择一系列属性来构造新类型，属性来源于`keys
> >
> > `pick`两个类型变量：
> >
> > - `T`：表示选择谁的属性`
> > - `keys`：表示选择哪几个属性（传入属性名，只能是第一个 类型变量中存在的属性）
> >
> > ```ts
> > interface IUser {
> >   readonly name: string;
> >   age: number;
> >   sex: 0 | 1;
> >   address: string;
> > }
> > // 选取了age与sex属性
> > type Person = Pick<IUser, "age" | "sex">;
> > // 结果就是
> > // {
> > //    age: number;
> > //    sex: 0 | 1;
> > // }
> > ```
>
>
>
> ==**Partial 可选项**==
>
> > `Partial` 已有的对象（必选+可选项）属性全部转化为`可选属性`
> >
> > ```ts
> > interface IUser {
> >   readonly name: string;
> >   age?: number;
> >   sex: 0 | 1;
> >   address: string;
> > }
> >
> > type Person = Partial<IUser>;
> > // 结果就是
> > // {
> > //    readonly name?: string;
> > //    age?: number;
> > //    sex?: 0 | 1;
> > //    address?: string;
> > // }
> > ```
>
>
>
> ==**Required 必选项**==
>
> > `Required`与`Partial`正好相反，已有的对象（必选+可选项）属性全部转化为`必选属性`
> >
> > ```ts
> > interface IUser {
> >   readonly name?: string;
> >   age?: number;
> >   sex?: 0 | 1;
> >   address: string;
> > }
> >
> > type Person = Required<IUser>;
> > // 结果就是
> > // {
> > //    readonly name: string;
> > //    age: number;
> > //    sex: 0 | 1;
> > //    address: string;
> > // }
> > ```
>
>
>
> ==**Readonly 只读**==
>
> > `Readonly` 已有的对象全部转化为带`Readonly只读属性`.(只读属性只能在定义变量的时候赋值，后面就不再允许赋值，赋值就报错)
> >
> > ```ts
> > interface IUser {
> >   readonly name?: string;
> >   age?: number;
> >   sex: 0 | 1;
> >   address: string;
> > }
> >
> > type Person = Readonly<IUser>;
> >
> > // obj 所有属性不能修改，只能读取了
> > // 结果就是
> > // {
> > //    readonly name?: string;
> > //    readonly age?: number;
> > //    readonly sex: 0 | 1;
> > //    readonly address: string;
> > // }
> > ```
>
>
>
> ==**Exclude 排除/不包括**==
>
> > `Exclude <T,U>` T属性排除U中已有的属性
> >
> > ```ts
> > type A = string | number | boolean;
> > type B = number | boolean;
> > type Person = Exclude<A, B>; // 结果就是 string
> > ```
>
>
>
> ==**Extract 提取/包括**==
>
> > `Extract <T, U>` 与`Exclude`正好相反，提取T与U相同的属性
> >
> > ```ts
> > type A = string | number | boolean | null;
> > type B = number | string;
> > type Person = Extract<A, B>;  // 结果就是 number | string
> > ```
>
>
>
> ==**ReturnType 函数的类型推导**==
>
> > `ReturnType` 获取函数返回值的类型
> >
> > ```ts
> > function getUser() {
> >   return {
> >     name: "vhen",
> >     age: 18,
> >     address: "北京",
> >   };
> > }
> > type ReturnUser = ReturnType<typeof getUser>; // 推导出了getUser函数的返回类型
> > // 结果就是
> > // {
> > //    name: string;
> > //    age: number;
> > //    address: string;
> > // }
> > ```
>
>
>
> ==**NonNullable 类型中排除 null 和 undefined**==
>
> > `NonNullable`从泛型 T 中排除掉 null 和 undefined
> >
> > ```ts
> > type A = string | number | null | undefined;
> > type B = NonNullable<A>; // 结果就是 string | number
> > ```
